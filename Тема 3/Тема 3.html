🔀Логические функции

Русская функция Английский аналог Описание
ЕСЛИ(условие; значение_если_истина; значение_если_ложь) IF Определяет значение ячейки в зависимости от условия.
ИЛИ(условие_1; условие_2; ... ) OR Возвращает true, если верно хотя бы одно из условий.
И(условие_1; условие_2; ... ) AND Возвращает true, если верны все условия.

📈Статистические функции

Русская функция Английский аналог Описание
МАКС(ячейка_1; ячейка_2; ...) MAX Определяет максимальное значение в ячейках или диапазоне ячеек.
МИН(ячейка_1; ячейка_2; ...) MIN Определяет минимальное значение в ячейках или диапазоне ячеек.
СЧЁТ(ячейка_1; ячейка_2; ... ) COUNT Возвращает количество ячеек, которые содержат числа.
СЧЁТЕСЛИ(диапазон; условие) COUNTIF Считает количество ячеек в диапазоне, которые удовлетворяют условию.
СЧЁТЕСЛИМН(диапазон_1; условие_1 [; диапазон_2; условие_2]; ... ) COUNTIFS Считает количество ячеек в диапазоне или разных диапазонах, которые удовлетворяют нескольким условиям.
СРЗНАЧ(значение_1; значение_2; ...) AVERAGE Считает среднее арифметическое значение нескольких значений.
СРЗНАЧЕСЛИ(диапазон, условия, [диапазон_усреднения]) AVERAGEIF Возвращает среднее значение в заданном диапазоне, используя условие отбора из этого диапазона.
НАИБОЛЬШИЙ(массив_значений; n) LARGE Возвращает n-й максимум в массиве значений.
НАИМЕНЬШИЙ(массив_значений; n) SMALL Возвращает n-й минимум в массиве значений.

➗Математические функции

Русская функция Английский аналог Описание
СУММ(ячейка_1; ячейка_2; ... ) SUM Считает сумму значений в ячейках или диапазоне ячеек.
СУММЕСЛИ(диапазон; условие; [диапазон_суммирования]) SUMIF Считает сумму значений в ячейках или диапазоне ячеек, удовлетворяющих некоторому условию. Можно указать диапазон для суммирования, который будет отличаться от проверяемого диапазона.
СУММЕСЛИМН(диапазон_суммирования; диапазон_проверки_1; условие_проверки_1; [диапазон_проверки_2; условие_проверки_2;] ... ) SUMIFS Считает сумму значений в ячейках или диапазоне ячеек, удовлетворяющих некоторому условию или нескольким условиям.
ОКРУГЛ(значение; кол_во_значащих_знаков) ROUND Округляет значение до определённого знака после запятой по правилам математики.
ОСТАТ(число; делитель) MOD Возвращает остаток от деления числа на делитель.
СТЕПЕНЬ(число; степень) POWER Возвращает число в степени.

🔍Поиск и другие функции

Русская функция Английский аналог Описание
ВПР(искомое_значение; таблица; номер_столбца [; интервальный_просмотр]) VLOOKUP Ищет значение в крайнем левом столбце таблицы и возвращает значение ячейки, находящейся в указанном столбце той же строки. Интервальный просмотр — логическое поле, 0 — точное совпадение, 1 — приблизительное совпадение при поиске значения.
💡 Совет: Зная английские аналоги функций, легко переносить формулы между Excel/Google Sheets с разной локализацией.
