🧮Единицы измерения информации

Для измерения информации используют специальные единицы измерения.

Бит — минимальная единица измерения информации.
Единица измерения Равна
1 байт (б) 8 бит (Б)
1 килобайт (Кб) 1024 байта (б)
1 мегабайт (Mб) 1024 килобайта (Кб)
1 гигабайт (Гб) 1024 мегабайта (Мб)
⚠️ Внимание: В задачах ЕГЭ по умолчанию используется именно степень двойки (1 Кб = 1024 б), а не 1000, если явно не указано иное.

🔢Общая формула (Формула Хартли)

N = 2i

  • N — мощность алфавита. Количество различных элементов, из которых может состоять информация.
  • i — объём (в битах), отводимый на одну единицу информации.

Python-функции для расчёта

Расчёт по формуле Хартли:

from math import log2, ceil

# Найти мощность алфавита N по известному i
i = 8
N = 2 ** i
print(N)  # 256

# Найти количество бит i по известному N
N = 256
i = log2(N)
print(i)  # 8.0

# Если N не является степенью двойки, i округляют вверх
N = 200
i = ceil(log2(N))
print(i)  # 8

🔤Текстовая информация

Текстовая информация состоит из символов. Пробелы и знаки препинания — это тоже символы.

V = l · i

  • l — длина текста (в символах).
  • i — объём (в битах), отводимый на один символ.

Python-код для расчёта объёма текста:

l = 1024  # длина текста в символах
i = 8     # бит на символ (256 символов алфавита)

V_bit = l * i
V_byte = V_bit / 8
print(V_bit, 'бит')
print(V_byte, 'байт')

🖼️Графическая информация

Изображение на экране формируется из пикселей.

V = w · h · i

  • w — ширина изображения (в пикселях).
  • h — высота изображения (в пикселях).
  • i — объём (в битах), отводимый на один пиксель (глубина цвета).

Python-код для расчёта объёма изображения:

w = 1920  # ширина в пикселях
h = 1080  # высота в пикселях
i = 24    # бит на пиксель (True Color)

V_bit = w * h * i
V_byte = V_bit / 8
V_mb = V_byte / 1024 / 1024
print(V_bit, 'бит')
print(V_byte, 'байт')
print(round(V_mb, 2), 'Мбайт')

🔊Звуковая информация

Звук — это волна, которая имеет амплитуду и частоту колебаний.

V = k · d · t · i

  • k — количество каналов (1 — моно, 2 — стерео, 4 — квадро и т.д).
  • d — частота дискретизации (в Гц).
  • t — время звучания (в секундах).
  • i — разрешение (глубина кодирования звука, в битах).

Python-код для расчёта объёма звукового файла:

k = 2       # стерео
d = 44100   # частота дискретизации, Гц
t = 180     # время звучания, сек
i = 16      # разрешение, бит

V_bit = k * d * t * i
V_byte = V_bit / 8
V_mb = V_byte / 1024 / 1024
print(V_bit, 'бит')
print(V_byte, 'байт')
print(round(V_mb, 2), 'Мбайт')

🎯Пример решения задачи

Условие задачи

Растровое изображение размером 192 на 960 пикселей занимает 90 Кбайт памяти без учёта заголовка файла. Известно, что для кодирования цвета каждого пикселя используется одинаковое количество бит. Какое максимальное количество цветов можно использовать в изображении?

Способ 1: Устное решение

Шаг 1. Переводим объём файла в биты

90 Кбайт = 90 × 1024 байта = 92 160 байт = 92 160 × 8 = 737 280 бит.

Шаг 2. Считаем количество пикселей

192 × 960 = 184 320 пикселей.

Шаг 3. Находим глубину цвета i

По формуле V = w · h · i выражаем i = V / (w · h):

i = 737 280 / 184 320 = 4 бита на пиксель.

Шаг 4. Находим количество цветов по формуле Хартли

N = 2i = 24 = 16.

📌 Ответ (Способ 1): максимальное количество цветов равно 16.

Способ 2: Программное решение

Python-код:

w = 192      # ширина изображения, пикс.
h = 960      # высота изображения, пикс.
V_kb = 90    # объём файла, Кбайт

V_bit = V_kb * 1024 * 8       # объём файла в битах
i = V_bit // (w * h)          # бит на пиксель
N = 2 ** i                    # максимальное кол-во цветов

print(f'i = {i} бит')
print(f'N = {N} цветов')

Программа выведет:

i = 4 бит
N = 16 цветов
📌 Ответ (Способ 2): 16

💡Ключевые моменты при решении

1️⃣ Направление формулы

Одну и ту же формулу можно применять в обе стороны: если известен объём V и размеры (w, h или l, или k, d, t), можно найти глубину кодирования i. И наоборот — зная i, можно найти объём V.

2️⃣ Единицы измерения

Перед подстановкой в формулу все величины нужно привести к одной системе единиц (обычно — к битам). Не забывайте, что 1 Кбайт = 1024 байта = 8192 бита.

3️⃣ Округление i

Так как на кодирование одного элемента всегда отводится целое число бит, при вычислении i через логарифм результат округляют вверх (в большую сторону), если он не является целым числом.

✅ Алгоритм решения любой задачи на измерение информации

  1. Определите тип информации (текст, графика, звук) и выберите нужную формулу
  2. Переведите все известные величины в единые единицы измерения (биты)
  3. Выразите неизвестную величину из формулы
  4. Если находите глубину кодирования i через логарифм — округлите результат вверх
  5. При необходимости примените формулу Хартли N = 2i, чтобы найти количество цветов/символов/уровней
