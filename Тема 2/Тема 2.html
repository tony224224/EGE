📐Таблица соответствия логических операций

Логические операции в задачах ЕГЭ записываются математическими символами. В Python они имеют другие обозначения:

Математический символ Описание Python оператор Пример
→ Импликация (если...то) <= A <= B
≡ Эквивалентность (равносильность) == A == B
∨ Дизъюнкция (ИЛИ) or A or B
∧ Конъюнкция (И) and A and B
¬ Отрицание (НЕ) not not A
💡 Совет: Запомните эти соответствия — они используются во всех задачах на логику!

🎯Способ 1: Прямой перебор значений

Условие задачи

Логическая функция F задаётся выражением:

F = (¬z ≡ y) → ((w ∧ ¬x) ≡ (y ∧ x))

Ниже приведён частично заполненный фрагмент таблицы истинности функции F, содержащий неповторяющиеся строки. Определите, какому столбцу таблицы истинности функции F соответствует каждая из переменных x, y, z, w.

Код решения (Способ 1)

Простой перебор всех возможных значений:

print('x y z w')
for x in range(2):
    for y in range(2):
        for z in range(2):
            for w in range(2):
                # Функция возвращает 0 в условии задачи, 
                # поэтому всё выражение помещаем под not
                if not((not(z) == y) <= ((w and not(x)) == (y and x))):
                    print(x, y, z, w)

Результат выполнения

Программа выведет таблицу значений:

x y z w
0 0 1 1
0 1 0 1
1 1 0 0
1 1 0 1

Анализ полученных значений

Из полученной таблицы нужно найти соответствие между переменными и их позициями в исходной таблице истинности:

  • Ищем строки, которые соответствуют условиям в задаче
  • Сопоставляем позиции переменных в полученной таблице с заданными строками
  • Определяем, какая переменная какому столбцу соответствует

🎯Способ 2: Полный расчет с перестановками

Этот способ автоматически находит правильный ответ без ручного анализа таблицы.

Как это работает

  • Генерируем все возможные значения неизвестных битов в таблице истинности
  • Проверяем, что все строки уникальны (неповторяющиеся)
  • Перебираем все перестановки переменных (24 варианта: 4! = 24)
  • Для каждой перестановки проверяем, верна ли логическая функция для всех строк
  • Выводим правильное соответствие переменных столбцам

Код решения (Способ 2)

Автоматический расчет с перестановками:

from itertools import product, permutations


def f1(x, y, z, w):
    return 1 if (not (z) == y) <= ((w and not (x)) == (y and x)) else 0


for a0, a1, a2, a3, a4, a5 in product((0, 1), repeat=6):
    s = [(a0, 1, 1, 1, 0),
         (1, 1, a1, a2, 0),
         (a3, a4, 0, a5, 0)]
    if len(set(s)) == len(s):
        for x, y, z, w in permutations((0, 1, 2, 3)):
            if all([f1(i[x], i[y], i[z], i[w]) == i[-1] for i in s]):
                print(f'x = {x + 1}; y = {y + 1}; z = {z + 1}; w = {w + 1}')
                break

Объяснение сложного кода

Разбор строк кода:

  • product((0, 1), repeat=6) — генерирует все 64 комбинации 6-ти неизвестных битов (a0-a5)
  • s = [(a0, 1, 1, 1, 0), ...] — создаёт таблицу с подставленными значениями и известной F=0
  • len(set(s)) == len(s) — проверяет, что все строки уникальны (нет дубликатов)
  • permutations((0, 1, 2, 3)) — генерирует все 24 способа расставить переменные x, y, z, w по позициям 0, 1, 2, 3
  • all([f1(...) == i[-1] for i in s]) — проверяет, что функция верна для всех строк таблицы
  • print(f'x = {x + 1}...') — выводит ответ: позиции переменных (номера столбцов)

💡Ключевые моменты при решении

Важные правила

1️⃣ Преобразование логических выражений

Логическое выражение нужно точно перевести из математической нотации в Python:

  • ¬ (отрицание) → not
  • ∧ (И) → and
  • ∨ (ИЛИ) → or
  • → (импликация) → <=
  • ≡ (эквивалентность) → ==

2️⃣ Скобочки и приоритет операций

В Python действует приоритет операций:

  • 1️⃣ not (отрицание)
  • 2️⃣ and (конъюнкция)
  • 3️⃣ or (дизъюнкция)
  • 4️⃣ <= (импликация)
  • 5️⃣ == (эквивалентность)

Совет: Всегда ставьте скобки явно, чтобы не ошибиться!

3️⃣ Функция возвращает 0 или 1?

Если в задаче F = 0, то условие в if нужно обернуть в not():

if not(выражение): — ищем строки, где функция равна 0

if выражение: — ищем строки, где функция равна 1
